# Customer Shopping Behavior Analysis | Python, SQL & Power BI

An end-to-end data analytics project focused on understanding customer shopping patterns, purchasing behavior, product preferences, and business performance using Python, SQL, and Power BI.

## 📌 Project Overview

Understanding customer behavior is essential for businesses to improve customer satisfaction, optimize marketing strategies, and make data-driven decisions.

This project analyzes retail customer shopping data to identify patterns in purchasing behavior, explore customer segments, and derive actionable business insights. It combines Python-based data cleaning and exploratory data analysis, SQL-based business analysis, and Power BI visualization into a complete analytics workflow.

## 🎯 Business Objectives

- Analyze customer purchasing patterns and shopping preferences.
- Understand customer segments and their spending behavior.
- Evaluate the relationship between discounts, subscriptions, and purchasing decisions.
- Identify popular product categories and customer preferences.
- Examine shipping preferences and customer ratings.
- Translate analytical findings into actionable business recommendations.

## 🔄 Project Workflow

### 1. Data Exploration and Cleaning — Python

Used Python and Pandas to inspect the dataset, understand its structure, check data quality, and prepare the data for analysis.

Key activities:
- Data loading and inspection
- Examination of data types and missing values
- Identification of potential data quality issues
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)

### 2. Business Analysis — SQL

Used SQL to answer business-oriented questions and uncover patterns in customer shopping behavior.

Analysis areas include:
- Customer segmentation and purchasing patterns
- Product category performance
- Spending behavior and purchase frequency
- Discount usage and subscription behavior
- Customer ratings and shipping preferences

SQL concepts applied include filtering, aggregation, grouping, joins where required, and analytical queries.

### 3. Dashboard Development — Power BI

Developed a Power BI dashboard to communicate findings through visualizations and interactive reporting.

The dashboard is intended to help users explore:
- Customer shopping trends
- Product and category performance
- Customer demographics and preferences
- Purchasing patterns and spending behavior
- Discount, subscription, and shipping trends

### 4. Reporting and Recommendations

Documented the analytical process and presented the business context, findings, and potential recommendations through a project report and presentation.

## ⚙️ Getting Started

### Prerequisites

Install or arrange access to the following tools:

- Python 3.x
- Jupyter Notebook
- Pandas and NumPy
- A supported SQL database, such as MySQL
- Microsoft Power BI Desktop

### Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
cd YOUR_REPOSITORY
```

Replace `YOUR_USERNAME` and `YOUR_REPOSITORY` with your GitHub details.

### Step 2: Install Python Dependencies

```bash
pip install pandas numpy jupyter
```

### Step 3: Run the Notebook

Open Jupyter Notebook:

```bash
jupyter notebook
```

Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute the cells in sequence. Update the dataset path or database connection settings if necessary.

### Step 4: Execute the SQL Queries

1. Set up your chosen SQL database.
2. Import the cleaned dataset into a database table.
3. Open `customer_behavior_sql_queries.sql` in your SQL editor.
4. Adjust table or column names if required.
5. Execute the queries to reproduce the business analysis.

### Step 5: Explore the Power BI Dashboard

Open `customer_behavior_dashboard.pbix` in Power BI Desktop. Configure the data source and refresh the data if prompted.
